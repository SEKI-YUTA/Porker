# テキサスホールデム ポーカー（Next.js版）

初心者向けのWebポーカー。CPU3人と対戦するテキサスホールデムです。

## 起動

```bash
npm install
npm run dev        # 開発サーバー → http://localhost:3000
```

本番ビルド:

```bash
npm run build
npm start
```

## 初心者向け機能

- **役の強さ一覧**: 右パネルに見本カード付きの役一覧を常時表示。いま自分にできている役をリアルタイム判定してハイライト
- **スターティングハンド表**: プリフロップの初期手札169通りの強さを13×13の色分けマスで表示。いま配られている自分の手札のマスが金色に光る
- **所持チップの常時表示**: トップバーと自分の手札エリアに、いま持っているチップを常に表示。ベットでリアルタイムに減算、勝利時は獲得バッジを表示
- **進行ステッパー**: 上部に「プリフロップ → フロップ → ターン → リバー → ショウダウン」を表示し、現在の段階を金色で強調
- **選択できないボタンの理由表示**: アクションボタンは常時5つ表示し、選択不可のものはグレーアウト。マウスホバー（タップ）で理由をツールチップ表示
- そのほか: アクション履歴ログ、遊び方ガイド、ベット額スライダー（最小〜オールイン＋プリセット）、効果音、キーボードショートカット（F / C / R）

## ルール

- テキサスホールデム、全員1,000チップ、ブラインド10/20（8ハンドごとに上昇）
- オールイン・サイドポット・分裂ポットに対応
- CPUは破産すると借金500で復活（借金額はシートに赤バッジで表示。上限1,500に達して破産したら脱落）
- あなたがチップ0になったらゲームオーバー。CPU全員を脱落させたら完全勝利

## 構成

```
app/            ページとグローバルCSS（App Router）
components/     UIコンポーネント（React・クライアントコンポーネント）
lib/poker/      ゲームロジック（フレームワーク非依存のTypeScript）
  cards.ts          山札・役評価（ベスト5枚選出）
  engine.ts         ゲーム進行エンジン（ベッティング/ストリート/配当）
  ai.ts             CPUの判断
  startingHands.ts  スターティングハンド表の強度分類
  queries.ts        UI表示用の状態計算（ボタン可否・理由など）
  sound.ts          WebAudio効果音
```

単一HTMLファイル版（ビルド不要）は `standalone.html`。
